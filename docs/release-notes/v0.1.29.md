# StreamFlow Lite v0.1.29 (pre-release)

Fixed
- Clicking **Audio processing** no longer turns the whole window black. A
  panel that fails now shows its error and a "Try again" button instead of
  taking the window down.

New
- **Source blocks**: a delete button (click twice, or press Delete), and drag
  a block left/right to change the layer order (left = on top).
- **Audio mixer → Audio settings** (and an FX button on every channel and on
  the master): low cut, high cut, AI noise removal, noise gate, 3-band EQ,
  de-esser, compressor (threshold, ratio, attack, release, make-up), limiter,
  delay, polarity / mono — each with its own on/off switch, plus Voice /
  Music / All off presets and live readings. The master has a −1 dB limiter
  on by default so the stream never clips.
- **Output → Video format**: 360p, 480p, 540p, 720p, 1080p and 1440p; bitrate
  with Low / Recommended / High picks for the chosen size and any custom
  value from 300 to 60000 kbps.
- **Video input** (top bar): what the camera / capture card itself captures —
  device, size, frame rate and device format from the list the device
  reports, Low / Balanced / High / Custom presets, and the real active input
  next to it. Separate from the stream output.

Lighter
- A still scene (colour, image, text) is drawn once instead of 30 times a
  second, and nothing is re-sent to the window until it changes.
  Measured (same benchmark, Linux CI runner, software GPU): engine CPU for
  such a scene 17.6 % → 0.4 % of a core.
- A hidden screen-capture source no longer grabs the screen.
- The preview monitor (studio mode) only transfers new pictures; meters slow
  down during silence and skip identical redraws.

Not measured: Windows hardware, GPU %, the window's own (WebView) CPU.
