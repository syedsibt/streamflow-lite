# StreamFlow Lite v0.1.27 (pre-release): fixes from real-PC testing + production workspace

## Fixed (root cause found, reproduced, tested)
- **"Could not reach the engine: shell lock poisoned".** A panic while the engine
  lock was held poisoned it, so every later command failed. The likely source:
  wgpu panics on any GPU validation error by default. Now:
  - GPU errors are recorded instead of panicking.
  - Texture sizes are checked.
  - The lock recovers from poisoning.
  - The video tick and the event loop contain panics.
  - Every internal error shows in Diagnostics and in
    `%LOCALAPPDATA%\StreamFlow\streamflow-errors.log`.
- **Audio "capture read failed: swresample run: Input changed".** A DirectShow
  mic reports only a channel count. We forced a stereo layout, so swresample
  rejected every real (mono) frame. Audio is now normalised per frame from its
  real format and rebuilt if the device changes format. Reproduced in a test
  (mono 48k/44.1k/16k, stereo 44.1k): before, the error; after, correct pitch on
  both channels.
- Device lists no longer hide errors ("None found") and no longer block the
  video tick while enumerating.
- Graded transparent overlays and text keep their transparency (shaders pass
  alpha through).

## New
- **Image source** (PNG, JPG, WebP, BMP, GIF first frame), transparency kept, not
  treated as video.
- **Per source:** move, resize, crop, rotate, opacity, lock, duplicate, layer order.
- **One production workspace:**
  - Preview | Cut/Auto | Program, with drag/resize on Preview.
  - Sources row with live status.
  - Scenes (reorder, keys 1–9).
  - Audio mixer: meters with peak hold and clip, fader, trim, pan, mute, solo
    (monitor only).
  - Properties: source, camera diagnostics, transform, color & LUT, audio processing.
  - Output: stream, record, format.
  - Status line: real CPU, GPU, memory, FPS, drops, latency, bitrate, with a
    2-minute chart.
- **GPU usage** from Windows "GPU Engine" counters (as Task Manager). Shows
  "Unavailable" with a reason when the OS can't report it.
