# StreamFlow Lite v0.1.26 (pre-release) — multi-camera compositor + studio mode

Includes everything in v0.1.25 (camera capture fixes + per-stage camera diagnostics + diagnostic test signal).

## Compositor (Sources → Scene → Compositor → Preview/Program → outputs)
- Per-source placement: position, size, crop (L/T/R/B), Fill / Fit / Stretch, opacity.
  A placed camera is GPU-scaled once to its box and only that rectangle is
  blitted (no full-frame blend per layer).
- Layout presets: side by side (fill or whole picture), top/bottom, picture-in-picture
  (4 corners), 2×2 grid, full.
- Shared captures: the same camera / screen in several scenes (or a duplicated scene)
  uses ONE capture — a device is never opened twice. Removing the original keeps the
  copies working.

## Studio mode
- Preview (green) and Program (red) monitors; Input edits the preview scene.
- Scenes strip: select (click or keys 1–9), rename (double-click), New, Duplicate, Delete.
- CUT (Enter) and AUTO (Space) with Mix, Fade-through-black or Wipe, 100–5000 ms.

## Tests
New: placement math (fill/fit/crop), placed-layer pixels, opacity blend, layouts,
fade/wipe frames, shared capture across duplicated scenes.
Not measured: real multi-camera load on Windows hardware.
