# StreamFlow Lite v0.1.28 (pre-release): lightweight pass

Measured on a 2-core VM with a software GPU (details: docs/RESOURCE_AUDIT.md):

- Idle with one test signal: CPU 102% → 24% of a core; engine 16.2 → 0.4 ms
  per frame; RAM 161 → 136 MB.
- Busy (video + PiP + logo + text + preview scene): CPU 125% → 58%;
  late frames 701 → 3 per minute; RAM 228 → 207 MB.

What changed:
- Ungraded sources skip the GPU round trip; opaque layers replace instead of
  blending on the GPU.
- Nothing is rendered when nobody looks and nothing is streamed or recorded.
- Monitor resolution follows its drawn size, and frames go to the UI as raw
  bytes (no base64).
- Cameras that aren't on Preview or Program stop decoding; they resume
  within one frame.
- Caches are bounded and released when sources are removed.
- The error log rotates at 256 KB, and the browser cache is capped at 1 MB.
- Fixed: the Program monitor showed the preview scene in studio mode.

Not measured: Windows hardware, GPU %, VRAM.
