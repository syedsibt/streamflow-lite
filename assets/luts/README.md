# Built-in LUTs

Built-in `.cube` 3D LUTs live in this directory.

- `identity-17.cube` — 17³ identity LUT (generated by `generate_identity.py`);
  maps every input color to itself. Used as the neutral reference for LUT
  plumbing and for ΔE accuracy checks against FFmpeg `lut3d`.
- `podcast_warm.cube` — 33³ warm-podcast LUT backing the built-in
  `podcast-warm.sflook` (which references it as
  `color/luts/podcast_warm.cube`). **Do not hand-edit**: it is produced by
  the committed generator `tools/gen-lut` (`cargo run -p gen-lut`);
  change the transform in `tools/gen-lut/src/main.rs` and re-run.
  Covered end-to-end by `crates/sf-engine/tests/lut_integration.rs`.

Project LUTs are referenced by relative path (e.g. `color/luts/podcast_warm.cube`)
and resolved against the `.streamflow` project directory at load time.
